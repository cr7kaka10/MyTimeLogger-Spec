# 管理方案：金币收支

> 文字版规则索引（2026-10-25）。金币余额以账本为准；正数入账，负数扣账。配置型金额以当前账户设置为准。

## 重点奖惩速览

<!-- CURRENT_GOAL_COIN_SUMMARY -->
- **V5 饮食：** 有训练安排且新政策生效后，六项必做规则每项逾期未完成扣 **20 金币**，六项全漏最多 **−120**。新政策从服务端首次升级后的下一个北京时间日开始。
- **运动身体记录：** 当天北京时间 **09:00** 前未完成要求的体重/体脂记录，扣 **50 金币**。
- **运动全项满分：** 当天计划全部应评分项目达到满分，奖 **100 金币**；可选/说明项不计入要求。
- **睡眠高额处罚（当前 V4）：** 无有效主睡眠 **−200**；睡眠周期少于4个 **−50**；深睡少于60分钟 **−20**。条件可叠加，三项同时命中合计 **−270**。
- **睡眠奖励（当前 V4）：** 八项全满 **+200**；睡眠评分按档最高 **+80**。评分低于60分是 **不获评分奖励（+0）**，不是额外扣币。

下文按金币账本来源列明各行为、金额和触发条件。评分、物品奖励或物品操作本身不代表金币收支。

> **休息日：** 自北京时间 **2026-10-26** 起，当天 gym 与 rain 方案均无有效训练项目时，V4/V5 均不生成饮食约束，饮食评分为 0/0，也不扣饮食金币。2026-10-26 之前的饮食记录和金币流水保持不变。

## 通用收支与其他流水

| 行为 / 账本来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 商店金币兑换 `reward_buy` | 按商品金币价扣除 | 任务/目标解锁等非金币兑换，仅在有扣款流水时扣币 |
| 自定义消费 `store_custom_spend` | 按录入金额扣除 | 1 金币 = 1 元 |
| 人工调整 `manual_adjustment` | 按调整值增减 | 正数补入，负数扣除 |
| 外部奖励 `external_claim` | 按领取奖励值增加 | 以外部奖励实际金币配置/流水为准 |
| 背包使用、丢弃 `backpack_use` / `backpack_discard` | 不直接改变金币 | 消耗或移除物品；物品来源奖励不等同金币 |

撤销打卡、改判状态或修正结算时，系统可能删除/更正原流水；余额随账本重算，不另设固定奖惩。其他未识别来源记作“系统流水”，以实际正负金额为准。

## 目标

| 行为 / 来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 目标达成 `goal_reward` | 取该目标的 `rewardCoins` 增加；未配置为0 | 达到目标设定的周期、指标和比较条件 |
| 目标未达成 `goal_penalty` | 取该目标的 `penaltyCoins` 扣除；未配置为0 | 到期结算未达标；目标奖惩独立配置 |

## 睡眠

| 行为 / 来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 睡眠评分 `sleep_settlement_reward` | 当前 V4：≥90分 +80；80–89 +50；70–79 +30；60–69 +10；<60 +0 | 每日按睡眠日期适用的服务端评分版本结算；未达60只是不发评分奖励 |
| 周期不足 `sleep_cycle_penalty` | −50 | 当前 V4：睡眠周期少于4；可与其他睡眠处罚叠加 |
| 深睡不足 `sleep_deep_penalty` | −20 | 当前 V4：深睡少于60分钟；可与其他睡眠处罚叠加 |
| 无有效主睡眠 `sleep_no_sleep_penalty` | −200 | 当前 V4：没有有效主睡眠记录；若同时周期不足、深睡不足，三项合计 −270 |
| 全项完成 `sleep_completion_reward` | 当前 V4 八项全满 +200；历史 V3 十项全满 +100 | 依睡眠日期对应版本，不能跨版本套用 |
| 入睡时间 `sleep_bedtime_adjustment` | 18:00–23:00 +20；23:01–23:30 +12；23:31–00:00 +6；00:01–01:00 0；01:01–02:00 −20；02:01–03:00 −40；03:01–04:00 −60；04:01–05:00 −80；05:01后/白天无效记录 −100 | 以有效入睡时间所在档结算；缺少有效入睡记录时待结算 |
| 晨晚日记 `sleep_morning_diary_reward` / `sleep_evening_diary_reward` | 每篇 +10 | 各自填写后独立奖励；旧规则曾以两篇均完成发放合计 +10（`sleep_diary_completion_reward`） |

评分分数不是金币：未命中睡眠评分奖励档且没有处罚条件时，不产生对应金币流水。
