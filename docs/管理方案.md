# 管理方案：金币收支

> 文字版规则索引（2026-10-25）。金币余额以账本为准；正数入账，负数扣账。配置型金额以当前账户设置为准。

## 通用收支与其他流水

| 行为 / 账本来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 商店金币兑换 `reward_buy` | 按商品金币价扣除 | 任务/目标解锁等非金币兑换，仅在有扣款流水时扣币 |
| 自定义消费 `store_custom_spend` | 按录入金额扣除 | 1 金币 = 1 元 |
| 人工调整 `manual_adjustment` | 按调整值增减 | 正数补入，负数扣除 |
| 外部奖励 `external_claim` | 按领取奖励值增加 | 以外部奖励实际金币配置/流水为准 |
| 背包使用、丢弃 `backpack_use` / `backpack_discard` | 不直接改变金币 | 消耗或移除物品；物品来源奖励不等同金币 |

撤销打卡、改判状态或修正结算时，系统可能删除/更正原流水；余额随账本重算，不另设固定奖惩。其他未识别来源记作“系统流水”，以实际正负金额为准。

## 目标

| 行为 / 来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 目标达成 `goal_reward` | 按目标奖励配置增加 | 达到目标设定的周期、指标和比较条件 |
| 目标未达成 `goal_penalty` | 按目标处罚配置扣除 | 到期结算未达标；未配置处罚则以实际流水为准 |

## 睡眠

| 行为 / 来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 睡眠评分 `sleep_settlement_reward` | ≥90分 +80；≥80 +50；≥70 +30；≥60 +10；低于60为0 | 按该日期适用的服务端评分版本结算 |
| 周期不足 `sleep_cycle_penalty` | −50 | 睡眠周期少于4 |
| 深睡不足 `sleep_deep_penalty` | −20 | 当前 V4 规则：深睡少于60分钟 |
| 无有效主睡眠 `sleep_no_sleep_penalty` | −200 | 当前 V4；同时触发周期/深睡处罚时合计 −270 |
| 全项完成 `sleep_completion_reward` | 当前 V4 八项全满 +200；历史 V3 十项全满 +100 | 依睡眠日期对应版本，不能跨版本套用 |
| 入睡时间 `sleep_bedtime_adjustment` | 18:00–23:00 +20；23:01–23:30 +12；23:31–00:00 +6；00:01–01:00 为0；之后每小时 −20，最低至 −100 | 01:01–02:00 −20、02:01–03:00 −40、03:01–04:00 −60、04:01–05:00 −80、05:01后/白天无效记录 −100；缺少有效入睡记录待结算 |
| 晨晚日记 `sleep_morning_diary_reward` / `sleep_evening_diary_reward` | 每篇 +10 | 各自填写后独立奖励；旧规则曾以两篇均完成发放合计 +10（`sleep_diary_completion_reward`） |

评分分数不是金币：未命中睡眠评分奖励档且没有处罚条件时，不产生对应金币流水。

## 学习

| 行为 / 来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 学习打卡、学习奖励 `learning_checkin` / `learning` | 按学习来源奖励配置增加 | 以关联学习项当前金币设置和实际流水为准 |
| 学习目标完成 `learning_objective_complete` | 按 O 级奖励配置增加 | O 下全部 KR 达标后，金币奖励幂等结算一次；物品奖励不算金币 |

## 运动

| 行为 / 来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 普通运动打卡/日结 `exercise_checkin` / `exercise_score` | 当前 V4/V5 仅打卡、计分不单独入金币；若历史账本有此来源，以流水为准 | 分数变化不等同金币变化 |
| 运动全项满分 `exercise_completion_reward` | +100 | 当天计划版本所有应评分项均满分；可选/说明项不阻塞 |
| 体重体脂逾期 `body_metric_deadline_penalty` | −50 | 北京时间09:00前未完成要求的身体数据记录 |
| 饮食约束逾期 `exercise_diet_penalty` | V4 每个未完成必做项 −20；V5 不扣金币 | V5 未达标只影响评分；以当天计划版本为准 |

## 习惯

| 行为 / 来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 习惯完成 `habit_checkin` / `habit` | 按该习惯金币奖励配置增加 | 每日打卡成功时结算；绑定物品另计，不是金币 |
| 习惯失败 `habit_fail` | 按该习惯处罚配置扣除 | 手动记失败或规则结算；实际金额以配置/账本为准 |

## 任务

| 行为 / 来源 | 金币影响 | 触发说明 |
|---|---:|---|
| 任务完成 `task_complete` / `task` | 按该任务金币奖励配置增加 | 清单任务完成时结算；绑定物品另计，不是金币 |
| 任务失败 `task_fail` | 按该任务处罚配置扣除 | 失败结算；若任务未配置处罚则不应假定固定扣币 |
