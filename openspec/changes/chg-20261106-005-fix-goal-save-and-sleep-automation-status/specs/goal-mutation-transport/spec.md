## ADDED Requirements

### Requirement: 目标写操作走当前平台网络通道
客户端 MUST 使用当前环境的认证信息，通过统一平台 HTTP 通道提交目标新增、编辑和删除。

#### Scenario: Android 编辑金币奖励
- **GIVEN** Android 已登录并连接当前环境服务端
- **WHEN** 用户修改目标奖励金币并保存
- **THEN** 客户端通过平台通道发送 PUT，成功后显示服务端确认的目标数据

#### Scenario: 网络及认证失败
- **GIVEN** 用户正在编辑目标
- **WHEN** 请求因网络故障或认证失效失败
- **THEN** 页面显示可理解的网络或登录提示，保留未提交的编辑内容

#### Scenario: 写入成功但同步失败
- **GIVEN** 服务端已确认目标写入
- **WHEN** 后续拉取同步失败
- **THEN** 页面 MUST 不把该写入显示为失败，并可在后续同步恢复数据
