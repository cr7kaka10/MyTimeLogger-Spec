## ADDED Requirements

### Requirement: 学习变更成功后当前页立即更新
系统 SHALL 在学习目标、KR、学习单元新增或 JSON 导入成功后，完成该次服务端变更的客户端拉取与本地合并，并在当前学习页展示最新数据，无需切换页面。

#### Scenario: 连续新增学习单元
- **GIVEN** 用户停留在同一个学习页且最近已有同步
- **WHEN** 用户连续新增学习单元且服务端返回成功
- **THEN** 每个学习单元均在当前 KR 下显示，数量与进度随数据更新

#### Scenario: 新增目标或 KR
- **GIVEN** 用户停留在学习页
- **WHEN** 用户新增目标或 KR 且服务端返回成功
- **THEN** 新目标或 KR 在当前页显示，无需切换页面

#### Scenario: 导入 JSON
- **GIVEN** 用户提交有效的学习计划 JSON
- **WHEN** 服务端导入成功
- **THEN** 当前页显示导入的目标、KR 和学习单元

### Requirement: 回读失败不得伪装成已刷新
系统 MUST 在服务端写入成功但客户端回读失败时给出可理解的提示，并提供重新读取最新内容的途径。

#### Scenario: 写入成功而同步失败
- **GIVEN** 服务端已经确认学习命令
- **WHEN** 后续拉取或本地合并失败
- **THEN** 页面提示内容已保存但尚未刷新，并允许用户重试读取，不自动重复提交创建命令
